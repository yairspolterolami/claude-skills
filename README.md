# Claude Skills

Shared Claude Code skills for the team.

## Installing a skill

Copy the skill's folder into `~/.claude/skills/` on your machine:

```
~/.claude/skills/
└── idea-validator/
    └── SKILL.md
```

The skill will be available in your next Claude Code session.

## Skills

| Skill | Description |
|-------|-------------|
| [idea-validator](./idea-validator/SKILL.md) | Brutally honest, research-backed validation for app/product ideas — gives a Build it / Maybe / Skip it verdict |
| [grill-me](./grill-me/SKILL.md) | Relentlessly interviews you about a plan or design to stress-test it — one question at a time, depth-first |
